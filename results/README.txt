Здесь приложение создаёт папки по дням конкурса (время Самары, UTC+4).
Каждая попытка — отдельный JSON с уникальным номером.
COLLECT_RESULTS.bat собирает Итоги_YYYY-MM-DD.xlsx внутри выбранной папки.
Удаляйте или архивируйте целиком папку дня только после окончания конкурса.
Удаление одного XLSX не удаляет попытки — таблицу можно собрать заново.
Не удаляйте папку дня во время работы участников.
