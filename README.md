# МИР • Промпт — сетевой конкурс

Прежнее приложение дополнено конкурсной механикой: 30 случайных заданий, офлайн-оценка по правилам: до 1000 за требования плюс полные минуты (до 1010 при лимите 10 минут), таймер 10 минут с автоотправкой, запись независимых попыток по дням и Python-сборщик Excel с местами.

**Сначала прочитай NETWORK_SETUP.md** — там сборка, сетевой диск, права доступа, проверка двух компьютеров и работа преподавателя.

- Запуск исходников на Windows: `START.bat`.
- Полноэкранный запуск исходников: `START_FULLSCREEN.bat`; в приложении — F11.
- Сборка Windows: `BUILD_PORTABLE.bat` → `dist/MirPrompt/MirPrompt.exe` и `MirPrompt_Portable_Windows.zip`.
- На компьютеры класса переносится целиком папка собранного приложения с `_internal`. Python участникам не нужен.
- Сборка Excel после конкурса: `COLLECT_RESULTS.bat` → выбрать дату → `results/дата/Итоги_дата.xlsx`.
- Сборщику нужен Python 3.11–3.13, дополнительных библиотек нет.
- Настройки рядом с EXE: `config.json`; лимит 600 секунд и множитель баллов 10 по умолчанию.
- Для очистки старого дня удали или архивируй целиком папку `results/дата` после окончания конкурса.

Одна строка Excel — одна попытка. Места: баллы по убыванию, затем длительность в миллисекундах по возрастанию. При полном равенстве место общее. Отмеченные алгоритмом спорные результаты проверяет организатор.

Итог = оценка требований по шкале 100 ×10 + полные оставшиеся минуты. При лимите 10 минут: отправка через 5:00 даёт бонус 5 (460 + 5 = 465), через 5:01 — бонус 4. Максимум 1010. Бонус начисляется и при нулевой оценке требований; при истечении времени бонус равен 0. Это проверка требований по словам, действиям, порядку и отрицаниям; она не гарантирует полное понимание произвольного текста. Задания и правила остаются отдельными модулями, готовыми для будущей интеграции.

Повторное участие с тем же именем и фамилией в один день блокируется на всех компьютерах с общей папкой результатов. Регистр и ё/е не различаются. Резервирование попытки сохраняется даже после закрытия приложения; нового дня ограничение не касается.

## Модули

`main.py` — оболочка Qt и локальный канал; `ui/` — интерфейс и иконка лебедя.
`session.py` — имя, выдача задания, время, фиксация результата.
`settings.py`, `config.json` — внешние настройки и день конкурса по Самаре.
`result_store.py` — атомарные отдельные JSON и локальная очередь восстановления.
`collect_results.py`, `ranking_excel.py` — валидация, места и XLSX через стандартную библиотеку Python.
`prompt_rules.py`, `tasks.json`, `TASKS.md`, `RULES_README.md` — независимый алгоритм и 30 заданий.

Имена принимают русские буквы, включая ё, и одиночные пробелы/дефисы между частями. Регистр нормализуется. Латиница, смешанный алфавит и цифры отклоняются. Проверка есть в интерфейсе и Python.

## Проверки

`python -m unittest discover -s tests -v` — правила, сессии, таймер, хранилище и Excel.
`node tests/test_ui.cjs` — контракт интерфейса с заменой DOM и Qt-канала.
Результаты проверки и ограничения — `TEST_REPORT.txt`.

Это архив исходников и средств сборки. Windows EXE в Linux не собирался; его нужно получить через BUILD_PORTABLE.bat на Windows. Запуск с сетевого диска необходимо проверить на учётных записях класса. Ошибки запуска оболочки пишутся в `%TEMP%/MirPrompt-startup-error.log`; содержимое формы там не журналируется.

Иконка: самостоятельный белый лебедь на синем фоне, созданный встроенным imagegen по запросу «Square Windows icon: bold white swan silhouette, curved neck and lifted wing, royal blue #0045ff background, flat graphic, generous margin, no text». Это не официальный знак университета; логотип колледжа в шапке сохранён.

Не смешивайте в одном конкурсе результаты прежней формулы ×10 и новой формулы с бонусом минут. Перед новым конкурсом перезапустите все приложения с новой сборкой и используйте отдельную папку дня. Сборщик отклонит смешанные формулы.
