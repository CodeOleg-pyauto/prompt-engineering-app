Задания оставлены короткими: описание потребности вместо готового пошагового промпта. Общие требования и шкала показываются всем участникам. Сохранены 30 тем и ID, чтобы не создавать параллельное приложение.

JSON намеренно имеет другую схему. **Нельзя переименовать его в корневой tasks.json:** текущий TaskPack понимает только старую шкалу 50+20+15+15 и поля 10/10/15/15.

В этом коммите добавлена только эта папка. Не меняются main, интерфейс, запуск, рабочие задания, конфигурация, результаты и старый оценщик. Нет новых зависимостей, EXE, персональных данных или секретов.

Загрузка ветки или cherry-pick добавит материалы, но не переключит рабочую оценку на 100. Подключение — отдельная задача после согласования.
