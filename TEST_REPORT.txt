МИР • Промпт — сетевой конкурс. Проверки 01.10.2026

Linux, Python 3.12.14, Node.js 24:
- python3 -m unittest discover -s tests -v: 40 тестов прошли.
- Проверены 30 эталонных промптов, пропущенные поля, отрицания, копирование,
  версии, синонимы, регистр, смешанный алфавит и фиксация результата.
- Проверены лимит 600 секунд, шкала 1000, пустая автоотправка и длительность.
- 100 попыток записаны 10 параллельными потоками: 100 отдельных JSON,
  без перезаписи и оставшихся временных файлов. Это проверка локальной ФС,
  а не измерение реального SMB-диска колледжа.
- Проверены сбой сетевой записи, локальная копия, повторное сохранение,
  восстановление после перезапуска и блокировка смены участника до записи.
- Проверены разные дни, дубликаты, повреждённые файлы, конфликтующие ID,
  смешанные шкалы, сортировка по баллам и времени и общие места при равенстве.
- node tests/test_ui.cjs: регистрация, баллы, повторные клики, ошибка проверки,
  повтор сохранения, блокировка смены участника, пустой таймаут и очистка прошли.
  Используется замена DOM/канала; это не запуск Qt или визуальный тест Windows.
- XLSX на 43 тестовых участниках успешно прочитан независимым XLSX-читателем:
  43 строки, 301 строка критериев, кириллица, баллы/время, фильтр, закреплённая
  шапка. XML и структура ZIP проверены. Формулы из текстовых полей не создаются.
- Сборщик отдельно запущен только с collect_results.py, ranking_excel.py,
  settings.py и config.json: создаёт XLSX без Qt и внешних Excel-библиотек.
- Синтаксис всех Python-модулей и JS проверен.

Windows EXE в этой среде не собирался и не запускался. Нет проверки реальных
учётных записей, прав NTFS/сетевой папки и SMB колледжа. Обязательно собрать
через BUILD_PORTABLE.bat на Windows и проверить две попытки в классе.
Алгоритм по правилам не гарантирует смысловую правильность произвольного текста.

Новая формула проверена: базовые баллы × множитель + полные оставшиеся минуты.
Границы 59.999/60, 299.999/300, 359.999/600 секунд и лимит проверены.
Пример 460 + 5 = 465 проверен. В Excel проверены итог, бонус, максимум
1010 и места по новой формуле. Старые записи читаются отдельно; смешивание
старой и новой формулы отклоняется. Интерфейс показывает разложение итога.
Проверены блокировка повторного участия и конкурентное резервирование имени.
Подтверждение отправки заменено обычным HTML-слоем; таймер интерфейса
не перерисовывается во время подтверждения. Визуальная проверка на Windows
по-прежнему требуется.
