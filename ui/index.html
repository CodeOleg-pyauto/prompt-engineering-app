      Готов отправить?

      После отправки редактировать промпт уже не получится. Приложение проверит требования задания по правилам и покажет баллы с пояснениями.

      Как проходит испытание

      1. Введи имя и фамилию.
      2. Прочитай задачу и составь запрос к ИИ.
      3. Отправь промпт и посмотри результат.

      Промпт — это текстовая инструкция для искусственного интеллекта. Знать программирование не обязательно.

      Каждый участник получает случайное задание из 30; задания могут повторяться. Оценка считается локально по одинаковой шкале: базовые баллы: сбор четырёх полей — 50, формирование и показ карточки — 20, порядок работы — 15, назначение и содержимое результата — 15. Итог: базовые баллы умножаются на 10, затем добавляется число оставшихся полных минут. Пример: 460 + 5 = 465. При лимите 10 минут максимум 1010. Чем быстрее отправлен промпт, тем больше бонус. При лимите 10 минут: 5:00 прохождения дают +5, 5:01 дают +4, по истечении времени +0. Это проверка требований по словарям и правилам: необычные формулировки может проверить организатор. Таймер запускается после выдачи задания. По истечении времени текущий текст автоматически отправляется на проверку. Результат записывается в папку конкурса; следующая попытка начинается с чистого экрана. Места определяются по баллам, при равенстве — по меньшему времени. База данных не используется.
