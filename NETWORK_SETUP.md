# Завтрашний запуск — МИР • Промпт

## 1. Сегодня на своём Windows собери новую версию

Распакуй архив целиком в новую локальную папку. Запусти `BUILD_PORTABLE.bat` и дождись завершения. Нужен уже установленный Python 3.11–3.13 x64 и интернет для установки библиотек. Новый EXE появится в `dist/MirPrompt/MirPrompt.exe`, а рядом с BAT — `MirPrompt_Portable_Windows.zip`.

Этот архив исходников не содержит готового Windows EXE. Старый EXE не получит таймер и сохранение от простого копирования новых Python-файлов — нужна новая сборка.

## 2. В классе

Распакуй **переносимый** архив на сетевой диск. Размещай всю папку `MirPrompt`, включая `_internal`, `config.json`, сборщик и `results`. Пример: `Z:/Конкурс/MirPrompt/MirPrompt.exe`.

Создай на компьютерах ярлыки на этот EXE или открой его сам. Каждый запуск — независимая попытка; задания могут повторяться. Участникам Python не нужен. Встроенной базы данных, сервера и платного API нет.

Учётным записям класса нужно разрешение читать и запускать приложение и создавать, переименовывать и удалять собственные временные файлы в `results`. Проверь права сетевой папки и NTFS с Юмашевым. Администраторские права не требуются самой механикой программы, но правила колледжа могут ограничивать запуск EXE и QtWebEngineProcess.exe с сетевого диска.

Сборку выполняй локально, а на сетевой диск переносится её готовая папка. Не запускай одновременно `BUILD_PORTABLE.bat` или подготовку исходников с десяти компьютеров.

## 3. Настройки до начала конкурса

`config.json` рядом с EXE:

- `time_limit_seconds`: 600 — 10 минут; можно изменить от 60 до 3600.
- `score_multiplier`: 10 — шкала 1000; 5 — шкала 500; 1 — шкала 100.
- `results_directory`: `results` — папка рядом с EXE. Можно указать абсолютный путь к другой общей папке.
- `event_day`: пустая строка — текущий день по Самаре (UTC+4). Можно закрепить день, например `2026-10-01`, одинаковый для всех компьютеров.

После изменения настроек перезапусти все экземпляры приложения. В ходе одного конкурса не меняй шкалу, лимит и пакет заданий: сборщик откажется определять места для смешанных условий.

Итоговые баллы = базовая оценка 0–100 × множитель + число полных оставшихся минут. При лимите 600 секунд отправка через 5:00 даёт бонус 5 (460 + 5 = 465), через 5:01 — бонус 4. Максимум при множителе 10 — 1010. При истечении времени бонус равен 0. Проверенные словари и правила сохранены; дополнительной смысловой точности у шкалы нет.

## 4. Проверка на двух компьютерах до прихода участников

1. Запусти приложение с сетевого диска под обычной учётной записью класса.
2. На двух компьютерах введи разные имена. Проверь случайное задание и таймер.
3. Отправь по промпту. Оба экрана должны показать «Результат сохранён в папке конкурса».
4. В `results/YYYY-MM-DD` должны появиться два разных JSON-файла.
5. На компьютере преподавателя запусти `COLLECT_RESULTS.bat`, выбери день, открой полученный Excel.
6. После проверки удали тестовую папку дня **до начала настоящего конкурса**. Если день один и тот же, приложение создаст папку снова для реальных участников.

Для проверки автоотправки можно временно поставить лимит 60 секунд, затем убрать тестовую папку, вернуть 600 и перезапустить приложение на всех компьютерах.

## 5. Во время конкурса

Таймер начинается при выдаче задания. Баллы и время фиксируются при отправке; передача файла по сети во время не входит. По истечении лимита отправляется текущий текст, даже пустой (0 за требования и 0 бонуса). Перед следующим участником дождись подтверждения сохранения и нажми «Завершить · следующий участник».

Если запись не удалась, приложение показывает состояние сохранения и кнопку повторной записи. Переключение на следующего участника заблокировано, пока результат не сохранён в общей папке. Локальная резервная копия, если её удалось записать, лежит на соответствующем компьютере: `%LOCALAPPDATA%/MirPrompt/pending`. При новом запуске с тем же путём к папке результатов приложение пробует восстановить такие записи автоматически, в папку их первоначального дня.

Если локальная копия тоже не записалась, не закрывай окно: результат пока в памяти. Восстанови доступ и нажми «Повторить сохранение».

## 6. После последнего участника

На компьютере преподавателя нужен Python 3.11–3.13 (удобно тот же Python 3.12). Excel-библиотеки устанавливать не нужно. Запусти `COLLECT_RESULTS.bat` из корня приложения. Выбери дату или нажми Enter для показанной даты.

Файл появится здесь: `results/YYYY-MM-DD/Итоги_YYYY-MM-DD.xlsx`.

- «Места»: место, имя, фамилия, баллы, максимум, время, задание, отметки проверки и автоотправки, компьютер и номер попытки.
- «Критерии»: подробные баллы каждой попытки.
- «О конкурсе»: правила ранжирования и число записей.
- «Ошибки»: появляется при повреждённых или конфликтующих файлах — проверь его до объявления победителей.

Порядок: больше баллов выше, при равенстве меньше времени выше. Если совпали и баллы, и миллисекунды, место общее: 1, 2, 2, 4. При призовой ничьей решение принимает организатор. Отметки «Нужна проверка» нужно разобрать до выдачи призов.

Повторный запуск сборщика пересобирает тот же Excel из исходных JSON без удвоения одинаковых номеров попыток. Если Excel уже открыт, закрой его перед сборкой. Приложение блокирует повторное участие с тем же именем и фамилией в один день (регистр и ё/е не различаются). Резервирования хранятся в `results/дата/.participants` и сохраняются после закрытия приложения. Для разрешённого организатором повторного старта нужно вручную удалить соответствующую запись резервирования; не очищай всю папку во время конкурса. Старые результаты с одинаковыми именами сборщик не объединяет.

## 7. Следующий день открытых дверей

С пустым `event_day` новый день получит отдельную папку автоматически. При закреплённой дате измени её или очисти настройку и перезапусти приложения. Старую папку дня можно перенести в архив или удалить целиком после окончания мероприятия. Предварительно убедись, что на всех компьютерах нет ожидающих сохранения результатов старого дня.

## Если запуск с сетевого диска не разрешён

Скопируй папку приложения локально на каждый компьютер, но укажи в `results_directory` **один общий абсолютный сетевой путь** на всех компьютерах. Например: `Z:/Конкурс/ОбщиеРезультаты`. Такой же путь установи в `config.json` рядом со сборщиком преподавателя. Для прямого UNC-пути в JSON обратные слеши удваиваются; проще использовать прямые слеши: `//server/share/Конкурс/ОбщиеРезультаты`.

Создание Excel не требует установленного Microsoft Excel; для просмотра нужен Excel или совместимое приложение. Windows EXE и запуск по SMB в среде разработки не проверялись — обязательна короткая проверка в классе.

Не смешивайте в одном конкурсе результаты прежней формулы ×10 и новой формулы с бонусом минут. Перед новым конкурсом перезапустите все приложения с новой сборкой и используйте отдельную папку дня. Сборщик отклонит смешанные формулы.
