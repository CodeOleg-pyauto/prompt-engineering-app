# 30 заданий «МИР • Промпт»

Учебные макеты: все задания имеют четыре входных поля и карточку результата.
Каждое задание оценивается по одной шкале до 100 баллов.

## task_01 — МЧС: карточка вызова

Составь промпт для создания учебного приложения для диспетчера МЧС. Приложение должно собирать информацию со слов пользователя. Не нужно писать программный код.

Обязательные требования:
1. Запросить: имя заявителя.
2. Запросить: пол со слов заявителя.
3. Запросить: адрес.
4. Запросить: причина вызова.
5. После получения ответов сформировать карточку вызова и показать её сотруднику.
6. Описать порядок: сначала сбор сведений, затем вывод результата.
7. Указать, что в карточке должны быть видны все четыре собранных значения.
