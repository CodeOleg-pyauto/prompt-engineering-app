МИР • Промпт — Колледж «МИР»

Запуск: MirPrompt.exe. Переносите всю папку вместе с _internal.
Python студентам не нужен. F11 — полноэкранный режим.
Настройки: config.json. Лимит 600 секунд, базовая шкала 1000 + полные оставшиеся минуты по умолчанию.
Пример: 460 + 5 минут = 465. Максимум при 10 минутах — 1010.

Результаты: results/дата/уникальный_номер.json.
Повторное участие с тем же именем и фамилией в один день блокируется на всех компьютерах с общей папкой результатов, в том числе после перезапуска.
После записи нажмите «Завершить · следующий участник».
Если сетевой диск недоступен, восстановите доступ и повторите сохранение.
Приложение показывает, записана ли локальная резервная копия.

После конкурса преподаватель запускает COLLECT_RESULTS.bat.
На его компьютере нужен Python 3.11–3.13; дополнительные библиотеки не нужны.
Выберите день. Excel с местами появится в папке этого дня.
Места: баллы, затем меньшее время; полное равенство — общее место.
Старый день можно удалить целиком одной папкой после окончания конкурса.

Подробная инструкция — NETWORK_SETUP.md.

Не смешивайте в одном конкурсе результаты прежней формулы ×10 и новой формулы с бонусом минут. Перед новым конкурсом перезапустите все приложения с новой сборкой и используйте отдельную папку дня. Сборщик отклонит смешанные формулы.
